# 🚀 ЗАПУСК FINAL DRONE SIMULATION

## Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск сервера
```bash
python final_drone_simulation.py
```

### 3. Открытие в браузере
Сервер автоматически откроет браузер на **http://localhost:8080**

## 🎯 Что вы получите

✅ **Городская 3D среда** с реалистичными зданиями  
✅ **Ультра-точная синхронизация** 10-100 наносекунд  
✅ **Интерактивная 3D визуализация** с Three.js  
✅ **Полный контроль** над роем дронов  
✅ **Реальное время** телеметрии и метрик  

## 🎮 Управление

- **Мышь** - вращение камеры
- **Колесо мыши** - масштабирование
- **Правая кнопка** - панорама
- **Предустановленные ракурсы** для лучших видов

## ⚙️ Настройки

- **Количество дронов:** 5-100
- **Радиус роя:** 10-2000 метров
- **Высота:** 10-500 метров
- **Типы часов:** Rubidium, OCXO, TCXO, Quartz
- **Модели помех:** Городская, пригородная, сельская
