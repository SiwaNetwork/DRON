## 1. 🚁 РАСЧЕТ ТЯГИ ДВИГАТЕЛЕЙ

### Пример 1.1: Расчет тяги одного двигателя

**Дано:**
- Диаметр пропеллера: D = 0.254 м
- Частота вращения: n = 120 об/с (7200 об/мин)
- Плотность воздуха: ρ = 1.225 кг/м³
- Коэффициент тяги: C_T = 0.1

**Решение:**
```
F_thrust = C_T · ρ · n² · D⁴
F_thrust = 0.1 · 1.225 · 120² · 0.254⁴
F_thrust = 0.1 · 1.225 · 14400 · 0.00416
F_thrust = 7.33 Н
```

**Ответ:** Тяга одного двигателя составляет 7.33 Н (≈ 0.75 кгс)

### Пример 1.2: Общая тяга квадрокоптера

**Дано:**
- 4 двигателя с одинаковой тягой
- Угол наклона дрона: θ = 15°

**Решение:**
```
F_total_vertical = 4 · F_thrust · cos(θ)
F_total_vertical = 4 · 7.33 · cos(15°)
F_total_vertical = 29.32 · 0.966
F_total_vertical = 28.32 Н
```

**Ответ:** Общая вертикальная тяга квадрокоптера составляет 28.32 Н

## 2. 🌪️ МОДЕЛИРОВАНИЕ АЭРОДИНАМИКИ

### Пример 2.1: Сила сопротивления воздуха

**Дано:**
- Скорость полета: v = 15 м/с
- Площадь проекции: A = 0.1 м²
- Коэффициент сопротивления: C_D = 1.2
- Плотность воздуха: ρ = 1.225 кг/м³

**Решение:**
```
F_drag = 0.5 · ρ · C_D · A · v²
F_drag = 0.5 · 1.225 · 1.2 · 0.1 · 15²
F_drag = 0.5 · 1.225 · 1.2 · 0.1 · 225
F_drag = 16.54 Н
```

**Ответ:** Сила сопротивления воздуха составляет 16.54 Н

### Пример 2.2: Модель ветра

**Дано:**
- Скорость ветра на высоте 10 м: v_wind_0 = 5 м/с
- Высота полета: z = 50 м
- Опорная высота: z_0 = 10 м
- Показатель степени: α = 0.14

**Решение:**
```
v_wind(z) = v_wind_0 · (z/z_0)^α
v_wind(50) = 5 · (50/10)^0.14
v_wind(50) = 5 · 5^0.14
v_wind(50) = 5 · 1.28
v_wind(50) = 6.4 м/с
```

**Ответ:** Скорость ветра на высоте 50 м составляет 6.4 м/с

## 3. ⏰ СИНХРОНИЗАЦИЯ ВРЕМЕНИ

### Пример 3.1: PNTP алгоритм

**Дано:**
- T₁ = 1000.000000 нс (отправка от мастера)
- T₂ = 1000.050000 нс (прием у ведомого)
- T₃ = 1000.100000 нс (отправка ответа)
- T₄ = 1000.150000 нс (прием ответа у мастера)

**Решение:**
```
offset = [(T₂ - T₁) - (T₄ - T₃)] / 2
offset = [(1000.050000 - 1000.000000) - (1000.150000 - 1000.100000)] / 2
offset = [0.050000 - 0.050000] / 2
offset = 0 нс
```

**Ответ:** Смещение времени равно 0 нс (часы синхронизированы)

### Пример 3.2: Фильтр Калмана

**Дано:**
- Шаг времени: Δt = 0.01 с
- Измерение смещения: z = 10 нс
- Дисперсия измерения: R = 25 нс²
- Дисперсия процесса: Q = 1 нс²

**Решение:**
```
F = [1  Δt  Δt²/2]   [1  0.01  0.00005]
    [0   1      Δt  ] = [0     1    0.01  ]
    [0   0       1  ]   [0     0      1   ]

H = [1 0 0]

K = P · H^T · [H · P · H^T + R]^(-1)
K = [P₁₁] · [P₁₁ + 25]^(-1)
```

**Ответ:** Коэффициент усиления Калмана зависит от априорной дисперсии P₁₁

## 4. 🎯 ФОРМИРОВАНИЕ СТРОЯ

### Пример 4.1: Круговая формация

**Дано:**
- Центр формации: p_center = [0, 0, 100]
- Радиус формации: r = 30 м
- Количество дронов: N = 8
- Высота формации: h = 100 м

**Решение:**
```
δ_i = [r·cos(2π·i/N), r·sin(2π·i/N), 0]

Для дрона 0 (i=0):
δ₀ = [30·cos(0), 30·sin(0), 0] = [30, 0, 0]

Для дрона 1 (i=1):
δ₁ = [30·cos(π/4), 30·sin(π/4), 0] = [21.21, 21.21, 0]

Для дрона 2 (i=2):
δ₂ = [30·cos(π/2), 30·sin(π/2), 0] = [0, 30, 0]
```

**Ответ:** Позиции дронов в круговой формации рассчитаны

### Пример 4.2: ПИД-регулятор позиции

**Дано:**
- Целевая позиция: p_ref = [10, 20, 100]
- Текущая позиция: p = [8, 18, 98]
- Коэффициенты: K_p = 2.0, K_d = 1.0, K_i = 0.1
- Ошибка интеграла: ∫e dt = 5

**Решение:**
```
e = p_ref - p = [10-8, 20-18, 100-98] = [2, 2, 2]
u = K_p · e + K_i · ∫e dt + K_d · de/dt
u = 2.0 · [2, 2, 2] + 0.1 · 5 + 1.0 · [0, 0, 0]
u = [4, 4, 4] + 0.5 + [0, 0, 0]
u = [4.5, 4.5, 4.5]
```

**Ответ:** Управляющий сигнал u = [4.5, 4.5, 4.5]

## 5. 🚫 ИЗБЕЖАНИЕ СТОЛКНОВЕНИЙ

### Пример 5.1: Искусственные потенциальные поля

**Дано:**
- Позиция дрона: p = [0, 0, 0]
- Позиция цели: p_goal = [10, 0, 0]
- Позиция препятствия: p_obstacle = [5, 2, 0]
- Коэффициенты: k_att = 1.0, k_rep = 10.0
- Радиус влияния: d₀ = 3 м

**Решение:**
```
d_goal = |p - p_goal| = √(10² + 0² + 0²) = 10 м
d_obstacle = |p - p_obstacle| = √(5² + 2² + 0²) = 5.39 м

U_att = 0.5 · 1.0 · 10² = 50 Дж

Так как d_obstacle > d₀, то U_rep = 0

U_total = 50 + 0 = 50 Дж

F = -∇U_total = -∇U_att = -k_att · (p - p_goal)
F = -1.0 · [0-10, 0-0, 0-0] = [10, 0, 0]
```

**Ответ:** Сила управления F = [10, 0, 0] Н направлена к цели

### Пример 5.2: Velocity Obstacle

**Дано:**
- Позиция дрона i: p_i = [0, 0, 0]
- Скорость дрона i: v_i = [5, 0, 0]
- Позиция дрона j: p_j = [10, 5, 0]
- Скорость дрона j: v_j = [-3, 0, 0]
- Радиусы: r_i = r_j = 1 м
- Время прогноза: τ = 2 с

**Решение:**
```
Относительная позиция: p_rel = p_j - p_i = [10, 5, 0]
Относительная скорость: v_rel = v_j - v_i = [-8, 0, 0]

Расстояние столкновения: d_collision = r_i + r_j = 2 м

Время до столкновения:
t_collision = |p_rel| / |v_rel| = √(10² + 5²) / 8 = 11.18 / 8 = 1.4 с

Так как t_collision < τ, то столкновение возможно
```

**Ответ:** Столкновение возможно через 1.4 секунды

## 6. 🛰️ GNSS МОДЕЛИРОВАНИЕ

### Пример 6.1: Ионосферная задержка

**Дано:**
- Угол возвышения: E = 45°
- Фактор наклона: F = 1.5
- Параметры модели: A₁ = 5×10⁻⁹, A₂ = 2×10⁻⁹, A₃ = 100

**Решение:**
```
I = F · [A₁ + A₂·cos(2π·(t - A₃)/365.25)]

Для t = 200 (200-й день года):
I = 1.5 · [5×10⁻⁹ + 2×10⁻⁹·cos(2π·(200-100)/365.25)]
I = 1.5 · [5×10⁻⁹ + 2×10⁻⁹·cos(2π·100/365.25)]
I = 1.5 · [5×10⁻⁹ + 2×10⁻⁹·cos(1.72)]
I = 1.5 · [5×10⁻⁹ + 2×10⁻⁹·(-0.16)]
I = 1.5 · [5×10⁻⁹ - 0.32×10⁻⁹]
I = 1.5 · 4.68×10⁻⁹ = 7.02×10⁻⁹ с = 7.02 нс
```

**Ответ:** Ионосферная задержка составляет 7.02 нс

### Пример 6.2: Тропосферная задержка

**Дано:**
- Высота над уровнем моря: h = 1 км
- Угол возвышения: E = 30°

**Решение:**
```
T_dry = 2.3 · exp(-h/7.35) / sin(E)
T_dry = 2.3 · exp(-1/7.35) / sin(30°)
T_dry = 2.3 · exp(-0.136) / 0.5
T_dry = 2.3 · 0.873 / 0.5 = 4.01 м

T_wet = 0.1 · exp(-h/2.2) / sin(E)
T_wet = 0.1 · exp(-1/2.2) / sin(30°)
T_wet = 0.1 · exp(-0.455) / 0.5
T_wet = 0.1 · 0.635 / 0.5 = 0.127 м

T_total = T_dry + T_wet = 4.01 + 0.127 = 4.137 м
```

**Ответ:** Общая тропосферная задержка составляет 4.137 м

## 7. 🔧 ОПТИМИЗАЦИЯ ПАРАМЕТРОВ

### Пример 7.1: Многоцелевая оптимизация

**Дано:**
- Ошибка формации: E_formation = 2.5 м
- Ошибка столкновений: E_collision = 0.1 м
- Энергопотребление: E_energy = 150 Вт
- Ошибка синхронизации: E_sync = 15 нс
- Ошибка связи: E_communication = 0.05

**Решение:**
```
Весовые коэффициенты: α₁ = 0.3, α₂ = 0.2, α₃ = 0.2, α₄ = 0.2, α₅ = 0.1

J = α₁·E_formation + α₂·E_collision + α₃·E_energy + α₄·E_sync + α₅·E_communication
J = 0.3·2.5 + 0.2·0.1 + 0.2·150 + 0.2·15 + 0.1·0.05
J = 0.75 + 0.02 + 30 + 3 + 0.005
J = 33.775
```

**Ответ:** Общая функция стоимости J = 33.775

### Пример 7.2: Адаптивные параметры

**Дано:**
- Начальные коэффициенты: K_p₀ = 2.0, K_d₀ = 1.0, K_i₀ = 0.1
- Коэффициенты адаптации: γ_p = 0.01, γ_d = 0.005, γ_i = 0.001
- Интеграл ошибки: ∫e²(t)dt = 25, ∫ė²(t)dt = 16, ∫(∫e(τ)dτ)²dt = 9

**Решение:**
```
K_p(t) = K_p₀ + γ_p · ∫ e²(t) dt
K_p(t) = 2.0 + 0.01 · 25 = 2.0 + 0.25 = 2.25

K_d(t) = K_d₀ + γ_d · ∫ ė²(t) dt
K_d(t) = 1.0 + 0.005 · 16 = 1.0 + 0.08 = 1.08

K_i(t) = K_i₀ + γ_i · ∫ (∫ e(τ) dτ)² dt
K_i(t) = 0.1 + 0.001 · 9 = 0.1 + 0.009 = 0.109
```

**Ответ:** Адаптированные коэффициенты: K_p = 2.25, K_d = 1.08, K_i = 0.109
