# 🚁 FINAL DRONE SWARM SIMULATION

## 🌟 Самая передовая 3D симуляция роя дронов

**`final_drone_simulation.py`** - это единый, полностью автономный файл со всеми зависимостями для ультра-точной симуляции роя дронов.

## ✨ Особенности

### 🏙️ **Городская 3D визуализация**
- **Реалистичные здания** и небоскребы
- **Городская инфраструктура** с улицами и районами
- **Детальные модели** зданий с окнами и антеннами
- **Городская среда** с соответствующими помехами

### ⚡ **Ультра-точная синхронизация**
- **Точность: 10-100 наносекунд**
- **V4 Enhanced PNTP** протокол
- **Rubidium часы** для мастер-узла
- **Адаптивная синхронизация** с DPLL
- **GPS дисциплинирование** часов

### 🎮 **Интерактивная 3D визуализация**
- **Three.js WebGL** рендеринг
- **Управление камерой** (мышь, колесо, правая кнопка)
- **Реалистичные модели** дронов
- **Динамические формации** и паттерны движения

### 🔧 **Продвинутые алгоритмы**
- **Аэродинамика** с расчетом подъемной силы и сопротивления
- **Физика полета** с учетом ветра и турбулентности
- **Модели помех** (urban/suburban/rural)
- **WWVB коррекция** времени
- **Аллан дисперсия** для анализа стабильности

## 🚀 Запуск

```bash
cd swarm_sync_system
python final_drone_simulation.py
```

Сервер автоматически откроет браузер на **http://localhost:8080**

## 🎯 Функции

### **Конфигурация роя:**
- Количество дронов (5-100)
- Радиус и высота роя
- Типы часов (Rubidium, OCXO, TCXO, Quartz)
- Модели помех (городская/пригородная/сельская)

### **3D управление:**
- **Мышь** - вращение камеры
- **Колесо мыши** - масштабирование  
- **Правая кнопка** - панорама
- **Предустановленные ракурсы**

### **Мониторинг:**
- Телеметрия в реальном времени
- Метрики синхронизации
- Статус каждого дрона
- Графики производительности
