# Обзор открытых разработок в области ГНСС-приёмников

Документ фиксирует результаты поиска открытых (open source / open hardware) наработок,
пригодных для заимствования при создании собственного многосистемного многочастотного
ГНСС-приёмника МГП-8. Дата обзора: 08.10.2026. Все репозитории, отмеченные «✔ клонирован»,
были загружены и изучены: проверены лицензии, состав, схемы и исходные тексты.

## 1. Сводный вывод

1. **Основа ВЧ-части — Pocket SDR FE 8CH** (Т. Такасу, Токийский университет морских наук
   и технологий). Это открытая плата KiCad (лицензия BSD-2, разрешено коммерческое
   использование). На ней 8 микросхем MAX2771 и USB 3.0-контроллер CYUSB3014 (FX3).
   Плата уже покрывает все гражданские сигналы диапазонов L1 (1525–1610 МГц)
   и L2/L5/L6 (1160–1290 МГц). Обвязку MAX2771 (согласование, фильтр ФАПЧ, тактирование)
   и частотный план мы берём оттуда, предварительно проверив их.
2. **Основа программной части — Pocket SDR (ПО)** (BSD-2). Это захват, слежение, декодирование
   навигационных сообщений и PVT почти для всех сигналов GPS, ГЛОНАСС (FDMA и CDMA), Galileo,
   BeiDou, QZSS, NavIC, SBAS. В основе — RTKLIB (BSD-2). На нём мы проверяем алгоритмы
   и сверяем результаты с эталоном.
3. **Открытого многосистемного коррелятора на ПЛИС не существует.** Есть только GPS L1 C/A
   и Galileo E1B в KiwiSDR (код А. Холма, GPL-3). У CTTC (GNSS-SDR) IP-ядро коммерческое,
   у Swift Navigation (SwiftNAP) — закрытое. Поэтому **коррелятор пишем сами**.
   Это главный собственный вклад проекта (см. `fpga/`).
4. **Эталонная модель** для проверки алгоритмов: Python-инструменты П. Монты
   (GNSS-DSP-tools, MIT): генераторы кодов и захват для всех сигналов. Для генерации
   тестовых сигналов: gps-sdr-sim (MIT), galileo-sdr-sim и SignalSim.
5. **Отечественная ЭКБ** для ВЧ-тракта многочастотного приёмника в открытом доступе
   не найдена. К1917ВА014 (НИИМА «Прогресс») — однокристальный приёмник только диапазона L1.
   Корреляторы НИИИС (1339ВП1Т1) поддерживают только ГЛОНАСС СТ/ВТ и GPS C/A.
   Для импортозамещения в ПЗ приведены возможные замены по цифровой части
   (МК, ПЛИС) и указаны риски.

**Решение:** собственный универсальный коррелятор на Verilog для ECP5 (открытый маршрут
yosys + nextpnr). Код дальномерной последовательности берётся из ОЗУ канала: ПО загружает
код любого сигнала. Поддерживаются BPSK, BOC(1,1) и FDMA-сдвиги. Каналы мультиплексируются
во времени. Подробно — в ПЗ, раздел «Цифровая обработка».

## 7. Интерфейсные документы (ИКД), обязательные для реализации

- GPS: IS-GPS-200 (L1 C/A, L2C), IS-GPS-705 (L5), IS-GPS-800 (L1C). Есть в репозитории gps-sdr-sim.
- ГЛОНАСС: ИКД ГЛОНАСС, ред. 5.1 (2008), сигналы FDMA L1/L2. ИКД сигналов с кодовым
  разделением L1, L2, L3, ред. 1.0 (АО «РКС», 2016): russianspacesystems.ru/wp-content/uploads/2016/08/.
- Galileo: OS SIS ICD (Issue 2.1), E6-B/C Codes Technical Note, HAS SIS ICD.
- BeiDou: BDS-SIS-ICD-B1I-3.0, B3I-1.0, B1C-1.0, B2a-1.0, B2b-1.0.
- QZSS: IS-QZSS-PNT-006, IS-QZSS-L6-005.
- NavIC: IRNSS SIS ICD for SPS 1.1, NavIC L1 SPS ICD.
- SBAS: RTCA DO-229.
