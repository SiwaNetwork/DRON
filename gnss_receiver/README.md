# МГП-8 — многосистемный многочастотный приёмник ГНСС (ШИВА.468157.001)

Открытая разработка модуля приёмника ГЛОНАСС/GPS/Galileo/BeiDou/QZSS/NavIC/SBAS.
В проект входят схема, конфигурация ПЛИС, программное обеспечение МК, моделирование
и конструкторская документация по ЕСКД.

Архитектура:

- 8 ВЧ-трактов MAX2771 (по схеме Pocket SDR FE 8CH), 2-битные I/Q, 24 МГц;
- ПЛИС LFE5U-45F (коррелятор на 80 каналов, режекторный фильтр, шкала времени, 1PPS);
- МК STM32H743 (захват, слежение, навигация, протоколы, шина FMC к ПЛИС);
- контроллер USB 3.0 FX3 для выдачи «сырых» отсчётов в формате Pocket SDR.

## Инструменты

Используются: Python 3 (numpy, scipy, matplotlib, reportlab), Icarus Verilog,
Yosys, nextpnr-ecp5 и Project Trellis (ecppack), ngspice, gcc и KiCad 7 (kicad-cli).
Для `tests/check_output.py` нужны также pyrtcm и pynmeagps.

## Проверка

```sh
# ПЛИС: движок коррелятора, режекторный фильтр, система целиком (сверка с моделями)
make -C fpga sim
# ПЛИС: синтез, размещение и трассировка, файл конфигурации build/mgp8.bit
make -C fpga syn
# ПО МК: модульные тесты (коды, модель ПЛИС, LNAV, строки ГЛОНАСС, решение, протоколы,
# спектр и режекторный фильтр, захват слабых сигналов) и сквозной «ПЧ → слежение» (L1 C/A)
make -C sw/fw test
# ПО МК: длительные тесты (≈ 35 мин): динамика 4g, слабые сигналы и повторный захват,
# сквозные «ПЧ → координаты, 1PPS» по GPS и по GPS + ГЛОНАСС
make -C sw/fw test-long
# расчёты (результаты — sim/out/*.md, *.png)
python3 sim/rf_budget.py; python3 sim/freq_plan.py; python3 sim/notch_sim.py
python3 sim/power_budget.py; python3 sim/reliability.py
# схема и перечни (Э3, ПЭ3, спецификация, ВП); текстовые документы (ТЗ, ПЗ, ПМ, описание программы)
python3 hw/gen/build.py
python3 tools/build_docs.py
# вычислительное ядро ПО МК для STM32H743 (arm-none-eabi-gcc)
make -C sw/fw mcu
```

## Цепочка верификации

Каждый вычислительный блок ПЛИС описан дважды: битово-точной моделью на Python
и моделью на C (`sw/fw/src/corr_sim.c`), на которой работает ПО МК в тестах.
Результаты RTL сверяются с моделью отсчёт в отсчёт. Тесты ПО МК используют ту же
модель ПЛИС, поэтому сквозная проверка «ПЧ → координаты» проходит через реальные
регистры и протокол обмена ПЛИС–МК.

Выходные протоколы NMEA и RTCM дополнительно проверяются независимыми декодерами
(pynmeagps, pyrtcm).
